This page describes how the public domain wrapper for the Discipline v2 recruiter portal handles data.

What this site does

This site is a static wrapper that embeds the published Google Apps Script recruiter portal in an iframe.

What data may be processed

  • the current page URL and its query parameters;
  • Google account identity resolved inside the Google Apps Script app;
  • portal data read from the internal Google Spreadsheet.

How access is controlled

Access is not granted by this wrapper itself. Access is checked inside the Google Apps Script application using the employee Google email and internal access flags from the service spreadsheet.
